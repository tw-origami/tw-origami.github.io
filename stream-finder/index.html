What this page can and can't do

This is the player half of Stream Finder, running entirely in your browser. Give it a direct stream link (.m3u8, .mp4, .webm) and it plays.

It cannot find a stream inside a web page, and it can't play streams that check the referer or require cookies. Both of those need a server: a browser page isn't allowed to read another site's content, and it can't set the Referer header — those are security rules with no way around them.

For that, run the full app locally with npm start and open 127.0.0.1:8971. It drives a real browser to find the stream and proxies playback with the right headers.
