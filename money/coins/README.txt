Real COIN images go here — one folder per coin, each with a FRONT and a BACK image.
The game shows front/back at random so kids learn to recognize both sides.

  coins/penny/front.png     coins/penny/back.png
  coins/nickel/front.png    coins/nickel/back.png
  coins/dime/front.png      coins/dime/back.png
  coins/quarter/front.png   coins/quarter/back.png

Tips:
  - Square images look best (each coin is clipped to a circle).
  - PNG with a transparent/plain background is cleanest. .jpg also works
    (name it front.jpg / back.jpg).
  - Missing an image? The game just shows a plain colored coin instead.
